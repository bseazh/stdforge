# AI 黑客松赛题需求原文

> 归档日期：2026-08-14  
> 说明：本文件依据参赛者提供的赛题信息整理，作为后续产品设计、方案分析和开发实现的需求基准。

## 一、企业

### 企业名称

海信容声（广东）冰箱有限公司

## 二、赛题信息

### 赛题

标准化功能需求（标准协同编辑 + 标准公告追踪 + 政策解读）

### 业务场景与使用对象

使用对象：标准化工程师、政策研究人员。

系统包含三大功能模块。

## 模块一：在线协同编辑标准、标准文本规范性审核

1. 引入 AI 大模型编辑。工程师输入技术要求，AI 参照 GB/T 1.1 等标准转化为标准化语言，并生成规范格式的文件；能够将技术文件转化为标准条款，生成标准文件（标准草案、编制说明、预研报告）等。

2. 实现标准在线协同编辑，对各项修改内容记录、留痕，生成制修订说明文件。考虑支持导入的表格、图片在线编辑；对导入的标准自动进行规范性审核，包括文本格式、常规的规范性用语、规范性引用文件等；编写完成的标准可直接生成结构化文本。

3. 同时生成英文版本，输出中英文版。

4. 支持线上预审、意见反馈、评审后意见上传及一键发起发布等功能。

5. 标准文本智能解析与问答。形成数字标准数据库，理解标准内容，精确检索、对比、分析、总结标准，并输出结论或触发系统功能／动作。

## 模块二：标准公告与标准组织

1. 外部标准研制信息：对接工信部等主要机构的国家标准、行业标准立项、计划下达等网站，并定期更新。

2. 直接推送国家标准发布、执行信息。

3. 外部标准组织筹建及换届信息：对接技术委员会筹备、换届及征集委员等通知网站。

4. 按照起草单位、技术领域统计分析（主要为外部标准，类似专利对比分析）。录入起草单位、技术领域等关键词，系统自动匹配相关联的企业（如海信芯片，可自动检索海信信芯微、纳真科技、乾照光电），分析其在相关领域主导或参与起草的标准情况，并生成报表、企业分布地图等可视化结果。

## 模块三：法律法规展示及政策解读

1. 政策收集：支持录入关键词、主要网站等信息进行相关政策自动收集，能够实时或按周收集。

2. 实时／定期更新：根据海信对外部网站访问策略要求，可以实时或定期更新所关注的信息。

3. 分级、分类管理：将收集到的与产业相关的政策信息按照两个维度进行展示，并支持检索，例如国家／地区、通用／产业专用分类。

4. 政策解读：聚焦与产业、行业相关性强的政策；明确各类政策的解读主体，尤其是共性政策的解读，避免因解读偏差导致不良后果。

5. 精准推送：根据配置的政策管理主体，精准推送相关政策信息给关注人员。
