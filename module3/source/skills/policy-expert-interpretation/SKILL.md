# 政策专家解读技能

将政策文件解读为面向白电/小家电行业企业的专家级分析报告。

## 适用场景

当用户需要解读工信部等部委发布的政策文件、法规、指南、目录等，并生成面向家电行业的专业解读报告时使用此技能。

典型触发场景：
- 用户提供政策文件链接或原文，要求进行行业解读
- 用户需要了解某政策对冰箱、洗衣机、空调、小家电等产品的影响
- 用户需要生成政策分析报告、合规指南、行动建议

## 解读框架

### 标准结构

政策专家解读报告应包含以下七个部分：

```
一、政策背景
   - 政策出台的背景和原因
   - 法律/法规依据
   - 政策脉络（与之前政策的关联）

二、政策目标
   - 政策要解决什么问题
   - 预期达到什么效果

三、核心内容
   - 主要规定了什么
   - 关键条款摘要（重点条款，非逐条）

四、行业影响分析
   - 对白电行业的影响（冰箱、洗衣机、空调）
   - 对小家电行业的影响
   - 影响程度判断：直接影响 / 间接影响 / 有限
   - 影响程度表格

五、企业核心要点
   - 需要重点关注的内容
   - 合规要求
   - 不做会怎样

六、行动建议
   - 企业应该做什么
   - 时间节点 / 过渡期安排
   - 建议的应对策略
   - 分阶段行动建议

七、风险提示
   - 容易理解偏差的地方
   - 模糊地带需要进一步确认
   - 常见误读
```

### 行业影响分析模板

对受影响的产品领域进行影响程度判断：

| 产品领域 | 影响程度 | 影响类型 |
|---|---|---|
| 冰箱 | 高/中/低 | 直接/间接/有限 |
| 洗衣机 | 高/中/低 | 直接/间接/有限 |
| 空调 | 高/中/低 | 直接/间接/有限 |
| 小家电（已纳入品类） | 高/中/低 | 直接/间接/有限 |
| 小家电（新增品类） | 高/中/低 | 直接/间接/有限 |

### 行动建议模板

建议按时间阶段组织行动建议：

**第一阶段：排查摸底（建议X个月内完成）**
- 具体行动项1
- 具体行动项2

**第二阶段：合规推进（建议X个月内完成）**
- 具体行动项1
- 具体行动项2

**第三阶段：完成合规（在过渡期内完成）**
- 具体行动项1
- 具体行动项2

## 文风要求

### 结构性要求

- 使用"一是...二是...三是..."的排比结构陈述核心内容
- 关键信息使用加粗标注
- 时间节点使用表格呈现
- 影响程度使用表格呈现

### 语言风格

- 正式、严谨，但不晦涩
- 参考工信部官方解读的语气和措辞
- 使用《政策名称》简称，避免重复全称
- 避免口语化表达

### 格式规范

- 标题层级：一级标题（一、二、三...）、二级标题（（一）（二）（三）...）
- 关键术语首次出现时使用全称，后续使用简称
- 重要时间节点单独列表
- 风险提示分条陈述

## 工作流程

### 步骤一：获取政策原文

1. 如果用户提供链接，使用 network-search skill 读取政策原文
2. 如果用户提供原文，直接使用
3. 确保获取完整的政策文件内容

### 步骤二：分析政策结构

1. 识别政策类型：新规、修订、指南、目录、办法等
2. 提取关键信息：发布部门、发布日期、生效日期、过渡期
3. 梳理核心条款和要求

### 步骤三：行业影响分析

1. 判断政策与白电/小家电行业的关联度
2. 分析对不同产品类别的影响程度
3. 识别直接影响和间接影响

### 步骤四：生成解读报告

1. 按照标准结构组织内容
2. 参考文风要求调整措辞
3. 确保每个部分都有实质内容

### 步骤五：质量检查

1. 检查是否遗漏重要条款
2. 检查行业影响分析是否充分
3. 检查行动建议是否具体可执行
4. 检查风险提示是否全面

## 输出格式

解读报告应以 Markdown 格式输出，包含：

- 报告标题
- 解读类型、适用行业、政策发布日期、解读日期
- 七个标准部分
- 解读依据（引用的法规和文件）
- 免责声明

## 注意事项

- 本技能生成的解读仅供参考，不构成法律意见
- 具体合规要求请以主管部门发布的正式文件为准
- 对于模糊条款，建议企业向主管部门或行业协会确认
