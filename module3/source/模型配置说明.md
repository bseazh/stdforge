# 政策分类大模型配置

当前分类接口兼容 OpenAI Chat Completions 请求格式，已使用 DeepSeek V4 Flash 完成真实验证。API Key 只在本地后端使用，不会发送到浏览器，也不得提交到 Git。

## 配置步骤

1. 在项目根目录复制 `.env.example`，并命名为 `.env.local`。
2. 填写以下三项：

```env
POLICY_LLM_BASE_URL=https://api.deepseek.com
POLICY_LLM_MODEL=deepseek-v4-flash
POLICY_LLM_API_KEY=你的APIKey
```

`POLICY_LLM_BASE_URL` 可以填写 API 的基础地址，也可以直接填写以 `/chat/completions` 结尾的完整调用地址。

3. 重新启动开发服务：

```powershell
npm run dev
```

4. 访问 `http://127.0.0.1:5173/api/health`。当返回以下字段时，说明配置已被后端读取：

```json
{
  "llmConfigured": true,
  "llmModel": "deepseek-v4-flash"
}
```

## 自动处理流程

```text
用户确认政策
→ 标题拆解 JSON
→ 按官方详情链接补抓已选政策全文
→ 基于全文生成内容摘要 JSON
→ 自动调用大模型
→ 返回政策层级、适用类型、置信度和判断依据
→ 用户确认或自定义调整
```

全文只在用户确认政策并进入任务二后读取，搜索列表阶段仍使用工信部检索摘要。这样既避免为所有候选结果请求详情页，也保证进入模型的已选政策尽量具有完整正文。内容 JSON 中的 `isFullText` 和 `sourceType` 可用于判断本次分析是否取得官方全文。

如果模型服务不是 OpenAI 兼容格式，或要求使用 `api-key` 等其他请求头，需要单独调整后端适配器。

## 政策分析报告

模块三复用同一组模型配置，并根据前端选择加载对应的本地 Skill：

- 专家解读型：`policy-expert-interpretation`
- 条款拆解型：`policy-clause-analysis`

后端会将官方详情页完整正文、Skill 指令、详细框架和分析主体一并提交给模型，返回 Markdown 报告。长报告调用显式关闭 DeepSeek 思考模式，避免输出预算被推理内容占用；政策发布日期只能使用采集元数据，解读日期由系统按当前日期传入。

## 双语标准翻译接口

双语能力是独立于文档生成的服务层。上游完成标准草案、编制说明或预研报告后，将标题和正文提交给接口；服务层按段落保留中文与英文的一一对应关系，页面可直接渲染为带中间分隔线的左右对照视图。英文人工校对后仅保存英文版本，不会覆盖中文版本。

默认复用 `POLICY_LLM_*` 配置。若后续接入独立的 DEP/翻译模型，可单独设置以下环境变量覆盖，不影响政策模块：

```env
BILINGUAL_LLM_BASE_URL=https://api.example.com
BILINGUAL_LLM_MODEL=translation-model
BILINGUAL_LLM_API_KEY=你的APIKey
```

当前适配器使用 OpenAI Chat Completions 兼容格式。若 DEP 的认证头、请求路径或响应格式不同，只需替换 `server/bilingual-translation.mjs` 中的 `callTranslator`，术语库、版本、下载和前端对照数据契约保持不变。

| 接口 | 作用 |
| --- | --- |
| `GET/POST /api/bilingual/glossary` | 查询、新增术语；默认带入制冷行业术语。 |
| `PATCH/DELETE /api/bilingual/glossary/{id}` | 修改、删除术语。 |
| `POST /api/bilingual/translations` | 生成双语对齐文档；`mode` 为 `parallel` 或 `english-only`。 |
| `GET /api/bilingual/translations/{id}` | 读取用于左右对照的段落数组、中文/英文版本快照。 |
| `PATCH /api/bilingual/translations/{id}/revisions` | 按 `language: zh/en` 单独保存中文或英文校对版本。 |
| `GET /api/bilingual/translations/{id}/download?language=zh|en|parallel` | 分别下载中文、英文或 Markdown 中英对照版。 |

生成请求示例：

```json
{
  "document": {
    "id": "draft-2026-001",
    "title": "家用制冷器具技术要求",
    "content": "# 范围\n\n本文件规定了家用制冷器具的技术要求。"
  },
  "mode": "parallel",
  "author": "标准化工程师"
}
```
