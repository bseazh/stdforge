# 汽车空调滤清器性能技术要求（演示输入）

> 本文为研发输入样例。所有数值是演示目标，待研发、质量和标准化人员确认，不是正式产品标准或认证承诺。

## 1. 项目与范围

| 字段 | 内容 |
| --- | --- |
| 项目名称 | 乘用车空调滤清器低阻高效项目 |
| 产品对象 | 乘用车 HVAC 系统用组合式空调滤清器 |
| 适用车型 | A 级至 B 级乘用车平台，演示接口尺寸 240 mm x 190 mm x 30 mm |
| 使用场景 | 城市道路、高粉尘道路和季节性高花粉环境 |
| 不适用范围 | 发动机进气滤清器、商用车重载滤清器、医用空气过滤设备 |

## 2. 结构与功能要求

1. 滤清器由滤材、边框、密封条和可选活性炭层组成，安装后不得明显漏风或松动。
2. 应拦截空气中的颗粒物，并在规定使用周期内保持可接受的通风阻力。
3. 含活性炭层的配置应具备基础异味吸附能力；具体污染物和判定方法待确认。
4. 材料不应有影响车内空气质量的异常气味，具体限值与目标市场法规待确认。

## 3. 性能指标

| 编号 | 指标 | 演示目标，待确认 | 验证条件 |
| --- | --- | --- | --- |
| F-01 | 初始阻力 | 额定风量下不大于 85 Pa | 常温干燥状态 |
| F-02 | 颗粒物过滤效率 | 对规定粒径颗粒不低于 90% | 试验粒径、风量和计数方法待确认 |
| F-03 | 容尘后阻力增长 | 规定容尘量后不大于 180 Pa | 额定风量 |
| F-04 | 结构完整性 | 振动后无裂纹、脱胶、滤材破损或影响安装的变形 | 按车辆运输/使用振动程序 |
| F-05 | 密封性 | 额定风量下旁路泄漏率不大于 5% | 装车模拟夹具 |

## 4. 试验条件与方法

- 样品数量：每种配置 5 件；演示目标，待确认。
- 试验空气温度 23 C +/- 5 C、相对湿度 45% 至 75%。
- 阻力在额定风量下测量，测点位于进出口静压段；仪器精度和管路尺寸待确认。
- 过滤效率采用上游/下游颗粒浓度计算，需明确颗粒物类型、粒径、采样位置和计数仪型号。
- 振动后复测阻力、效率和安装状态；外观和泄漏情况应拍照记录。

## 5. 判定与交付

1. 所有样品应满足 F-01 至 F-05；失效样品应记录失效位置与原因。
2. 输出设计图纸、材料清单、滤材规格、检测原始数据、颗粒物计数记录和试验报告。
3. 目标市场、气味/VOC 评价方法、容尘试验粉尘类型和安装夹具尚待确认。

## 6. 参考与待确认事项

- 待确认：目标车型接口、公差、额定风量、测试粉尘、颗粒粒径、气味/VOC 限值和法规适用性。
