# 车载冰箱温控与性能技术要求（演示输入）

> 文档属性：研发技术要求样例。本文中的性能数值均为**演示目标，待研发确认**，不是正式产品承诺或标准限值。

| 产品名称 | 车载冰箱 |
| 适用型号 | CF-20 演示型号，20 L，DC 12 V / 24 V |

## 2. 范围与边界

本技术要求适用于采用直流压缩机制冷的便携式车载冰箱，规定其温度控制、制冷性能、能耗、噪声、运输可靠性和试验验证要求。

不适用于吸收式车载冰箱、医用冷链设备及仅具保温功能的储物箱。

## 3. 术语与产品配置

- 额定内容积：制造商声明的可用于储存物品的有效容积。
- 设定温度：用户在控制面板选择的目标箱内温度。
- 温度波动：稳定运行期间箱内温度的最大值与最小值之差。
- 测温包：按试验方法规定布置、用于模拟储存负载温度的测试件。
- 产品配置：压缩机、冷凝风机、蒸发器、电子温控器、显示与告警模块、电池低压保护模块。

## 4. 功能要求

1. 用户可设置 -18 C 至 10 C 的目标温度，显示分辨率不低于 1 C。
2. 应具备制冷、保温、低压保护和故障告警功能。
3. 电源输入在 DC 10.8 V 至 16 V 或 DC 21.6 V 至 32 V 范围内应能正常工作。
4. 低压保护触发后，应停止压缩机运行并保留告警状态；恢复至设定阈值以上后可自动或手动恢复。
5. 断电恢复后，应恢复断电前的设定温度及工作模式。

## 5. 可量化性能目标

| 编号 | 技术指标 | 演示目标，待研发确认 | 条件/备注 |
| --- | --- | --- | --- |
| P-01 | 降温时间 | 环境温度 32 C 下，空载由 25 C 降至 4 C 不大于 90 min | DC 12 V 供电 |
| P-02 | 温度控制偏差 | 稳态平均温度与设定温度偏差不超过 +/- 2 C | 设定 4 C |
| P-03 | 温度波动 | 24 h 内不大于 4 C | 测温包中心温度 |
| P-04 | 保温性能 | 断电 2 h 后箱内温升不大于 8 C | 初始箱温 4 C，环境温度 32 C |
| P-05 | 日耗电量 | 设定 4 C、环境温度 32 C 时不大于 0.55 kWh/24 h | 稳态运行 |
| P-06 | 运行噪声 | A 计权声功率级不大于 48 dB(A) | 半消声室测量 |
| P-07 | 低压保护 | 12 V 模式下低压切断阈值 10.8 V +/- 0.3 V | 可配置档位待确认 |
| P-08 | 运输振动后功能 | 按运输振动试验后，外观无影响安全的损坏且功能正常 | 见 7.6 |

## 6. 安全、环境与可靠性要求

1. 与食品接触的内胆和密封材料应满足相应材料安全要求。
2. 制冷剂及电气安全要求应符合项目适用的法规和企业规范；具体引用标准由标准化工程师确认。
3. 产品在 0 C 至 43 C 环境温度范围内应无结构性损坏、无异常焦味和无失控运行。
4. 包装后的产品应承受运输振动；试验后应满足 P-08。
5. 外观件应无锐利边缘，铭牌、警示标签和接线标识应清晰、耐久。

## 7. 验证方案

### 7.1 样品与抽样

- 型式验证样品数量：3 台；演示目标，待研发确认。
- 每台样品应为量产状态，并记录型号、序列号、软件版本、制冷剂批次。
- 一项不合格时复测一次；复测仍不合格则该项目判定不合格。批次判定规则待质量部门确认。

### 7.2 通用试验条件

| 项目 | 条件 |
| --- | --- |
| 环境温度 | 32 C +/- 1 C，除非另有规定 |
| 相对湿度 | 45% 至 75% |
| 供电 | DC 12.0 V +/- 0.2 V，或按产品标称输入 |
| 放置条件 | 水平放置，距墙壁不小于 0.5 m |
| 稳定判据 | 连续 3 h 的平均温度变化不超过 1 C |
| 数据采集 | 间隔不大于 1 min，温度计准确度不低于 +/- 0.5 C |

### 7.3 降温时间试验

将样品在通用试验条件下通电稳定 1 h，箱内初始温度为 25 C +/- 1 C，设定温度为 4 C。记录从启动至测温包中心温度首次达到 4 C 的时间，结果应满足 P-01。

### 7.4 温度控制与波动试验

样品在设定温度 4 C 下运行至稳定，连续记录 24 h。计算平均温度与设定温度的差值，以及记录期间最大温度与最小温度的差值，结果应满足 P-02、P-03。

### 7.5 能耗与噪声试验

能耗按 24 h 稳态运行的电能计量值折算；噪声在背景噪声满足测量要求的场地测量。结果分别应满足 P-05、P-06。

### 7.6 运输振动试验

包装状态下按企业运输振动程序进行试验。振动谱、方向、持续时间和包装跌落条件尚未确认，需由质量与包装工程师补充后生成正式条款。

## 8. 验收与交付

1. 试验报告应包含样品信息、环境条件、仪器编号及校准状态、原始数据、计算结果、异常说明和结论。
2. 不满足任一强制性安全要求时判定为不合格。
3. 需提交产品规格书、关键部件清单、电气原理图、测试原始记录和风险评估记录。
