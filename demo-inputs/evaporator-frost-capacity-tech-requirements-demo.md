# 家用电冰箱蒸发器容霜性能技术要求（演示输入）

> 本文为研发输入样例。所有数值是演示目标，待研发、质量和标准化人员确认，不是 QB/T 8144-2025 的复述或正式限值。

## 1. 项目与范围

| 字段 | 内容 |
| --- | --- |
| 项目名称 | 风冷冰箱蒸发器容霜性能提升项目 |
| 产品对象 | 家用风冷无霜冰箱用翅片式蒸发器 |
| 适用型号 | RF-480 演示平台，冷藏室蒸发器 |
| 目标场景 | 高湿环境下延长化霜间隔并保持送风能力 |
| 不适用范围 | 直冷冰箱、商用冷柜、非翅片管式换热器 |

## 2. 技术目标

1. 蒸发器在规定湿热工况下运行至化霜触发前，应维持设计送风能力。
2. 结霜后不应出现影响风道密封、风机运行或排水的冰堵。
3. 化霜完成后，残余积水应在规定时间内排尽，不应造成二次结冰。

## 3. 性能指标

| 编号 | 指标 | 演示目标，待确认 | 验证条件 |
| --- | --- | --- | --- |
| E-01 | 容霜质量 | 不小于 650 g | 规定湿热工况、规定试验时长 |
| E-02 | 送风衰减 | 不大于初始风量的 15% | 结霜前后同一档位测量 |
| E-03 | 化霜完成时间 | 不大于 35 min | 化霜程序启动至蒸发器表面无连续霜层 |
| E-04 | 排水完成时间 | 不大于 15 min | 化霜结束后记录排水口无连续滴水 |
| E-05 | 再冻结 | 不应出现影响运行的冰堵 | 化霜后恢复制冷 2 h |

## 4. 试验条件与方法

- 样品数量：3 台整机或 3 套蒸发器系统；演示目标，待确认。
- 环境温度：32 C +/- 1 C；相对湿度：70% +/- 5%。
- 箱内负载、门开闭程序、化霜触发逻辑及测温点布置需由研发补充。
- 使用经校准的电子天平、温湿度记录仪、风量计和数据采集系统；采样间隔不大于 1 min。
- 容霜质量按试验前后质量差计算；风量衰减按结霜后风量相对初始风量的变化率计算。

## 5. 判定与交付

1. 每个样品均应满足 E-01 至 E-05；一项不合格时允许复测一次。
2. 试验报告应包含蒸发器结构、翅片间距、制冷剂充注量、化霜策略、原始曲线、结霜照片和结论。
3. 需提交风道结构图、化霜控制逻辑、排水结构图及失效模式分析。

- 可参考 QB/T 8144-2025《家用电冰箱蒸发器容霜能力要求和评价方法》的章节分类；具体条文和适用性需核验原文。
- 待确认：结霜质量计算边界、负载量、门开闭程序、测点位置、化霜终止判据和统计判定规则。
