# 公共场所集中空调通风系统清洗消毒技术要求（演示输入）

> 本文为运维/服务方案的研发输入样例。所有频次、浓度和阈值均为演示目标，待卫生、安全和客户方确认，不可作为公共卫生规范直接执行。

## 1. 项目与范围

| 字段 | 内容 |
| --- | --- |
| 项目名称 | 商业综合体集中空调通风系统清洗消毒项目 |
| 服务对象 | 某商业综合体空调通风系统，演示项目 |
| 覆盖范围 | 风管、风口、空气处理机组、冷凝水盘、过滤网及相关部件 |
| 使用场景 | 日常维护、季节性启用前清洗、投诉或污染风险事件后的专项处置 |
| 不适用范围 | 医疗机构特殊区域通风系统、实验室高等级生物安全系统 |

## 2. 流程与功能要求

1. 作业流程应包含现场勘查、风险评估、隔离防护、清洗、消毒、效果评价、废弃物处置和记录归档。
2. 作业前应确认系统停机状态、送回风区域、人员疏散与施工告知。
3. 清洗和消毒过程不得造成二次污染，不得损坏风管内衬、过滤器或电气部件。
4. 作业人员应按风险等级配置个人防护用品，并接受安全交底。

## 3. 技术指标

| 编号 | 指标 | 演示目标，待确认 | 验证条件 |
| --- | --- | --- | --- |
| C-01 | 覆盖率 | 计划清洗部位覆盖率 100% | 按勘查清单核对 |
| C-02 | 表面积尘 | 清洗后按双方确认的采样方法达到目标值 | 采样位置和限值待确认 |
| C-03 | 消毒剂使用 | 按产品说明书和风险评估确定浓度、作用时间及通风要求 | 不预设化学品浓度 |
| C-04 | 系统恢复 | 作业后风机、阀门、控制与排水功能正常 | 恢复运行前检查 |
| C-05 | 记录完整性 | 作业记录、影像、检测数据和废弃物去向齐全 | 项目归档检查 |

## 4. 作业条件与验证方法

- 作业前进行风管路径、污染情况、检修口、用电点、消防设施和人员动线勘查。
- 按区域建立清洗清单；每个部位记录位置编码、作业时间、使用设备、作业人员和前后照片。
- 清洗设备应配置集尘、负压或隔离措施，具体参数由现场风险评估确定。
- 消毒剂品类、浓度、作用时间、残留控制和废液处置应以客户批准方案及产品说明书为准。
- 效果评价可包含目视检查、表面采样、空气采样和功能复核；抽样比例、方法和阈值待确认。

## 5. 验收与交付

1. 验收资料应包含勘查报告、风险评估、作业方案、人员资质、材料安全信息、过程记录、检测记录、问题整改和结论。
2. 发现系统损坏、污染扩散或安全风险时应立即暂停作业并报告客户方。
3. 项目完成后应形成可追溯的“清洗消毒服务记录表”和“意见/问题闭环表”。

## 6. 参考与待确认事项

- 可参考 WS/T 10005-2023《公共场所集中空调通风系统清洗消毒规范》的章节结构；正式适用条款和当地监管要求需专业人员确认。
- 待确认：服务场所类别、采样方法、消毒剂、浓度、作用时间、环境安全措施、验收限值和废弃物处置要求。
